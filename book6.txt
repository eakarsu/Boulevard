Retrieving Client Information
Learn how to supplement the Booking API with additional client information to create a customized and unique client experience.

Note: Client specific data like past appointments requires the use of a scoped and authenticated client token. Please refer to the Authenticated Client API Access in the Client API overview for more information on how to generate an authenticated client token.

Retrieving Client Appointment History
The below query filter queries for appointments before a specific date and at a specific location. If no search query is supplied, the default response will return all appointments (past and future) for all locations.

See AppointmentConnection for the full API reference.

query {
  myAppointments(
    first: 20,
    query: "startAt <= '2020-07-30T00:00:00-07:00' AND locationId = 'urn:blvd:Location:fc647375-0946-4ad8-8cce-57dfc34189c8'"
  ) {
    edges {
      node {
        id
        startAt
        endAt
        duration
        cancelled
        state
        clientId
        client {
          id
          name
        }
        location {
          id
          name
          businessName
        }
        notes
        appointmentServices {
          price
          startAt
          endAt
          startTimeOffset
          totalDuration
          duration
          staffId
          staff {
            id
            firstName
            lastName
          }
          serviceId
          service {
            name
            categoryId
            category {
              name
            }
          }
        }
      }
    }
  }
}

Retrieving Client Memberships
Display membership status and details in your custom client experience.

See MembershipConnection for the full API reference.

query {
  myMemberships(first: 10) {
    edges {
      cursor
      node {
        termNumber
        startOn
        endOn
        clientId
        client {
          firstName
          lastName
        }
        status
        name
        vouchers {
          quantity
          service {
            id
            name
          }
        }
      }
    }
  }
}
