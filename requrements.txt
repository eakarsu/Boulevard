# Comprehensive Aider Prompt for Building Boulevard Clone from Scratch

Based on your browser screenshot showing the Boulevard platform and the comprehensive feature set, here's a complete Aider prompt for rebuilding Boulevard from zero:

```
You are an expert full-stack developer tasked with creating a complete Boulevard clone - a comprehensive client experience platform for appointment-based, self-care businesses (salons, spas, barbershops, wellness centers). This system should be production-ready, scalable, and include all Boulevard's core features.

## PROJECT OVERVIEW
Create a modern, web-based client experience platform using React/TypeScript frontend, Node.js/Express backend, PostgreSQL database, and real-time capabilities. The system should support multi-location businesses with advanced scheduling optimization.

## CORE SYSTEM ARCHITECTURE

### Frontend Requirements (React/TypeScript)
- Modern responsive UI using Tailwind CSS with Boulevard's clean aesthetic
- Real-time updates using WebSocket connections for live booking updates
- Mobile-first design optimized for tablets and smartphones
- Touch-friendly interface for service providers
- Client self-booking portal with real-time availability
- Staff dashboard with color-coded scheduling interface
- Role-based access control (Owner, Manager, Staff, Client)
- Progressive Web App (PWA) capabilities for offline functionality

### Backend Requirements (Node.js/Express)
- RESTful API with GraphQL integration for complex queries
- JWT authentication with refresh token rotation
- Real-time WebSocket server for live schedule updates
- Payment gateway integration (Stripe, Square)
- SMS/Email notification system (Twilio, SendGrid)
- Advanced scheduling algorithm (Precision Scheduling™ clone)
- Multi-tenant architecture for franchise support
- Comprehensive audit logging and analytics
- Data backup and disaster recovery systems

### Database Schema (PostgreSQL)
Design complete database with these core entities:
- **Users**: roles (owner, manager, staff, client), authentication, preferences
- **Businesses**: multi-location support, settings, branding
- **Locations**: address, hours, capacity, staff assignments
- **Services**: categories, duration, pricing, staff requirements
- **Staff**: skills, availability, commission rates, performance metrics
- **Clients**: profiles, history, preferences, loyalty points
- **Appointments**: bookings, status, notes, payments
- **Availability**: staff schedules, time blocks, exceptions
- **Payments**: transactions, methods, refunds, tips
- **Inventory**: products, stock levels, suppliers
- **Marketing**: campaigns, automations, loyalty programs
- **Reports**: analytics, performance metrics, financial data
```
